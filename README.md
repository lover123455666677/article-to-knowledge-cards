# make-knowledge-cards

把一篇文章转换成 5~8 张知识卡片的 AI Agent Skill。卡片面向复习与自测：每张只讲一个知识点，包含标题、核心知识、简明解释、例子或自测问题。

## 项目解决什么问题

- 长文是线性的，真正需要记住的知识点淹没在背景、叙述和重复表述中，读完后难以快速复习。
- 手工整理笔记重复耗时，还常见两个问题：为凑条数把一个点拆成多条，或加入原文没有的“补充知识”。
- 本 Skill 让 Agent 按固定流程把文章提炼成**一卡一点、可自测、可追溯到原文**的卡片，直接用于复习和知识巩固。

## 主要功能

- 支持两种输入：直接粘贴的文章正文、本地 `.md` / `.txt` 文件
- 输出 5~8 张 Markdown 知识卡片，每张包含：标题、核心知识、简明解释、例子或自测问题
- 只提取真正重要的知识；背景铺垫、情绪表达、纯叙事不做成卡片
- 一张卡片只讲一个知识点，自动合并文中重复出现的内容
- 不编造原文没有的信息（包括“看似合理”的推论）
- 信息不足时按实际数量输出并说明原因，不凑数；知识点超过 8 个时只保留最重要的 8 张

## 目录结构

```text
skills/make-knowledge-cards/
├── SKILL.md            # Skill 元数据与完整工作流程
└── agents/
    └── openai.yaml     # Agent 接口描述（显示名、默认提示词）
```

本 Skill 是纯指令型 Skill，**不包含脚本，日常使用没有任何运行时依赖**。

## 安装方法

环境要求：一个支持 Agent Skills 格式（`SKILL.md`）的 AI Agent。

1. 将 `skills/make-knowledge-cards` 整个目录复制到 Agent 的 Skill 加载目录。
   - 例如在豆包中，放入 `<Doubao 数据目录>\.doubao\agent_mode\workspace\.user_skills\`，使最终路径为 `…\workspace\.user_skills\make-knowledge-cards`（具体路径以你的环境为准）。
   - 其他 Agent：放入其文档指定的 skills 目录，或将本项目的 `skills` 目录加入 Skill 搜索路径。
2. 重新加载或重启 Agent，使其发现新 Skill；无需安装任何依赖。
3. （可选）安装后可用 Skill 创建工具提供的 `quick_validate.py` 校验目录结构，需要 Python 和 PyYAML：

   ```bash
   python quick_validate.py skills/make-knowledge-cards
   # 输出：Skill is valid!
   ```

## 使用方法

1. **直接粘贴文章正文**，然后说：“把这篇文章做成知识卡片”。
2. **给出本地文件路径**，仅支持 `.md` 和 `.txt`，例如：“用 make-knowledge-cards 处理 notes/操作系统笔记.md”。

类似“做成复习卡片 / 学习卡片 / 提炼知识点 / 总结成可自测的内容”的说法都会触发该 Skill。结果默认以 Markdown 直接输出在对话中；也可以要求保存为 `.md` 文件（本地文件输入时默认命名为 `<原文件名>.cards.md`）。

## 输入输出示例

输入（`honey.txt`）：

```text
蜂蜜结晶是正常现象。蜂蜜中的主要糖分是葡萄糖和果糖，其中葡萄糖在低温
环境下会从蜂蜜中析出、形成细小晶体，温度低于14摄氏度时结晶更容易发生。
结晶并不代表蜂蜜变质，也不影响其营养价值。如果想让结晶的蜂蜜恢复液态，
可以把蜂蜜瓶放在温水中隔水加热，温度不要过高。
```

输出：

```markdown
# 知识卡片：蜂蜜结晶

## 卡片 1：结晶是正常现象且不影响品质
- **核心知识**：蜂蜜结晶是正常现象，不代表变质，也不影响其营养价值。
- **简明解释**：结晶只改变蜂蜜的外观和状态，并不代表蜂蜜变质，其中的营养成分也没有受到影响。
- **例子/自测**：自测：蜂蜜出现结晶，是否说明它已经变质？

---

## 卡片 2：结晶是葡萄糖在低温下析出
- **核心知识**：蜂蜜中的葡萄糖在低温环境下析出形成细小晶体，温度低于 14℃ 时更容易发生。
- **简明解释**：蜂蜜的主要糖分是葡萄糖和果糖，低温环境下葡萄糖会从蜂蜜中析出、形成晶体；温度低于 14℃ 时，这一过程更容易发生。
- **例子/自测**：自测：蜂蜜结晶主要与哪种糖分、什么环境条件有关？

---

## 卡片 3：温水隔水加热可恢复液态
- **核心知识**：想让结晶蜂蜜恢复液态，可把蜂蜜瓶放在温水中隔水加热，温度不要过高。
- **简明解释**：按照这一方法，把蜂蜜瓶置于温水中隔水加热、避免温度过高，即可让结晶的蜂蜜恢复液态。
- **例子/自测**：自测：恢复结晶蜂蜜的正确加热方式是什么？

---

> 原文信息量不足，仅能提取 3 个独立知识点，故未凑足 5 张。
```

## 不支持的场景

- 网页抓取（URL）：不抓取网页，请粘贴正文或保存为 `.md`/`.txt`
- PDF、Word、图片、音视频：不解析，请先转换为 Markdown 或纯文本
- Anki 牌组（`.apkg`）导出：只产出 Markdown 文本
- 图形界面与卡片图片生成
